# Focalors Discord AI Bot

Discord assistant bot integrating Google Gemini with live web search capabilities and persona modeling.

## Features

* Natural language conversation powered by Google Gemini
* Dynamic web search grounding for real-time queries
* Persistent conversational memory and persona formatting

## Tech Stack

* Python 3.10+
* discord.py
* google-generativeai
* requests
* BeautifulSoup4

## Setup

1. Install required packages:

```bash
pip install discord.py google-generativeai requests beautifulsoup4
```

2. Configure bot tokens in your environment or configuration file.

3. Run the bot:

```bash
python bot.py
```
